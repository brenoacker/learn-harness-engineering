# Rubrica do Avaliador

Use esta rubrica após implementação e antes da aceitação final.

| Categoria | Pergunta | Pontuação (0-2) | Notas |
| --- | --- | --- | --- |
| Correção | O comportamento implementado corresponde à feature solicitada? |  |  |
| Verificação | As verificações necessárias realmente executaram, com evidência? |  |  |
| Disciplina de escopo | A sessão ficou dentro do escopo da feature escolhida? |  |  |
| Confiabilidade | O resultado sobrevive a restart ou rerun sem reparo? |  |  |
| Manutenibilidade | O código e documentação estão claros o suficiente para a próxima sessão? |  |  |
| Prontidão de handoff | Uma sessão nova pode continuar o trabalho apenas com artefatos do repo? |  |  |
