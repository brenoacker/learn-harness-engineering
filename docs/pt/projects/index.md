# Bem-vindo aos Projetos

Esta é a seção hands-on do Learn Harness Engineering. Ler as lectures não é suficiente—você precisa construir os ambientes você mesmo e observar como Codex, Claude Code, ou outros agentes de IA se comportam sob diferentes regras.

## Visão Geral dos Projetos

Este curso apresenta 6 projetos progressivos e práticos que ensinam como construir um ambiente de trabalho agêntico confiável do zero:

1. **Prompt-Only vs. Rules-First**: Compare como um agent performa apenas com um prompt versus um harness básico.
2. **Agent-Readable Workspace**: Aprenda como estruturar seu repositório para torná-lo amigável à IA e estabelecer mecanismos de handoff.
3. **Multi-Session Continuity**: Projete arquivos de estado e scripts de inicialização para que seu agent possa retomar o trabalho perfeitamente através de sessões.
4. **Runtime Feedback and Scope Control**: Introduza ferramentas que permitem ao agent testar seu próprio código e corrigir erros durante a execução.
5. **Self-Verification and Role Separation**: Construa um mecanismo de revisão independente para prevenir alucinações e declarações precoces de vitória.
6. **Complete Harness (Capstone)**: Monte um ambiente de trabalho de agent final, observável e end-to-end.

## Como Proceder

Cada pasta de projeto tipicamente contém:
- `starter/`: Seu workspace inicial.
- `solution/`: Uma implementação de referência (se você ficar preso).
- Instruções de tarefa detalhando seu background e objetivos específicos.

Use seu AI Coding Agent preferido (ex: Claude Code, Cursor, Trae) para completar as tarefas dentro do diretório `starter/`.
